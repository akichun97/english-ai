# Emma — изучение языков с ИИ-преподавателем (английский, японский, турецкий)

Работает на Android и iPhone (одна кодовая база, Expo / React Native).
Своего сервера нет: приложение напрямую обращается к ИИ (Claude) по ключу,
который вводит пользователь в «Настройках».

## Что умеет
- **Два языка**: английский (A1–C1) и японский (N5–N1). Прогресс по языкам отдельный, язык меняется в профиле.
- **Стартовый тест** определяет уровень. Темы выше уровня закрыты и открываются, когда пройдены все темы текущего.
- **Уроки**: правило, объяснение «почему так и как читается», примеры с транскрипцией (для японского — ромадзи) и звуком, кнопка «Почему так?».
- **Emma**: переписка и голосовой урок. В голосовом уроке Emma на экране, её эмоции меняются по ходу разговора. Японскому новичку Emma говорит в основном по-русски.
- **Итог урока**: ошибки, новые слова (добавляются в словарь) и совет.
- **Практика**: словарь с карточками и интервальным повторением, тренажёр произношения, аудирование, тесты и экзамены.
- **Цель дня и напоминания** от Emma в выбранный час.
- **Достижения**: некоторые открывают новые образы Emma.
- **Статистика**: опыт за 7 дней, выученные слова, минуты разговора.
- **Тёмная тема** и автоматическая по настройкам телефона.

## Как посмотреть на телефоне (без сборки)
1. Установите на телефон приложение **Expo Go** (Google Play / App Store).
2. На компьютере в этой папке: `npm install`, затем `npx expo start`.
3. Отсканируйте QR-код телефоном.

## Как получить APK для Android
APK собирается автоматически на GitHub при каждом изменении в ветке `main`
(файл `.github/workflows/android-apk.yml`). Готовый файл лежит в разделе
**Releases** репозитория. Скачайте `.apk` на телефон и откройте его
(Android попросит разрешить установку из неизвестных источников).

Новые сборки ставятся поверх старых: все они подписаны одним и тем же стандартным
ключом. Перед публикацией в Google Play нужно завести собственный ключ подписи.

Запасной способ: `eas build -p android --profile apk` через аккаунт expo.dev.

## iPhone
APK на iPhone не ставится. Нужен аккаунт Apple Developer (99 $ в год), затем
`eas build -p ios --profile ios-testflight` и `eas submit -p ios` — раздача через TestFlight.

## Где что лежит
- `App.tsx` — вкладки внизу экрана.
- `src/ai.ts` — подключение к ИИ и характер преподавателя.
- `src/data/lessons.ts` — темы и задания (новые уроки добавлять сюда).
- `src/data/tests.ts` — тест на уровень и список экзаменов.
- `src/screens/` — экраны.
