# English AI — прототип приложения для изучения английского с ИИ

Работает на Android и iPhone (одна кодовая база, Expo / React Native).
Своего сервера нет: приложение напрямую обращается к ИИ (Claude) по ключу,
который вводит пользователь в «Настройках».

## Что умеет первая версия
- **Уроки**: 4 темы (Знакомство, Present Simple, Путешествия, Past Simple) с теорией и заданиями.
  Тесты с вариантами проверяются сразу, переводы и свободные ответы проверяет ИИ.
- **Разговор**: чат с преподавателем Emma. Режимы: свободный разговор, ролевая игра, собеседование,
  IELTS Speaking. Ошибки поправляются с объяснением по-русски. Долгое нажатие озвучивает ответ.
- **Тесты**: тест на уровень (A1–C1) и экзамены IELTS / TOEFL / ЕГЭ / по уровню, задания создаёт ИИ.
- **Прогресс**: опыт (XP), дни подряд, пройденные темы. Хранятся только на телефоне.

## Как посмотреть на телефоне (без сборки)
1. Установите на телефон приложение **Expo Go** (Google Play / App Store).
2. На компьютере в этой папке: `npm install`, затем `npx expo start`.
3. Отсканируйте QR-код телефоном.

## Как собрать APK для Android
1. Бесплатный аккаунт на expo.dev, затем `npm install -g eas-cli` и `eas login`.
2. `eas build -p android --profile apk` — через ~15 минут будет ссылка на APK.
3. Новая версия: поднять `version` в `app.json` и собрать снова.

## iPhone
APK на iPhone не ставится. Нужен аккаунт Apple Developer (99 $ в год), затем
`eas build -p ios --profile ios-testflight` и `eas submit -p ios` — раздача через TestFlight.

## Где что лежит
- `App.tsx` — вкладки внизу экрана.
- `src/ai.ts` — подключение к ИИ и характер преподавателя.
- `src/data/lessons.ts` — темы и задания (новые уроки добавлять сюда).
- `src/data/tests.ts` — тест на уровень и список экзаменов.
- `src/screens/` — экраны.
